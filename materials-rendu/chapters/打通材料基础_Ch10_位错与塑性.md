\section{1. 一句话本质}

\begin{bluebox}
\textbf{金属的塑性变形 = 位错在晶体里滑移}。\textbf{位错让滑移"逐个原子"进行,
而非"整层同时",所以金属的实际强度比理论低百倍——金属因此能加工}。

\vspace{0.3em}

\textbf{三句话记住这一章}:

\textbf{1. 位错滑移由"分切应力"驱动}:Schmid 定律 $\tau = \sigma\cos\phi\cos\lambda$——\textbf{取向决定难易}。

\textbf{2. 位错让金属"软"}:整层滑移要 $G/10$ 的应力,位错滑移只要百分之一——\textbf{所以金属能锻造}。

\textbf{3. 位错让金属"越锤越硬"}:位错运动 → 增殖 → 缠结 → 越来越难动(加工硬化)。

\vspace{0.3em}

\textbf{实测核心 Aha}:\textbf{完美晶体的理论强度比实际高约 143 倍——位错填平了这个差距};
\textbf{Schmid 因子最大 0.5(45°软取向最易变形,轴平行滑移面时为 0 根本不动)};
\textbf{加工硬化让位错密度从 $10^{11}$ 涨到 $10^{15}$,强度大增(连接 Ch3)}。
\end{bluebox}

\section{2. 教科书里你看到的}

\subsection{位错运动的方式}

\begin{longtable}{|l|p{0.6\textwidth}|}
\hline
\rowcolor{primarycolor!10}
\textbf{方式} & \textbf{说明} \\
\hline
滑移(glide) & 沿滑移面运动,不需扩散——\textbf{常温塑性的主力} \\
攀移(climb) & 垂直滑移面运动,需空位扩散——\textbf{高温蠕变(连接 Ch8)} \\
交滑移(cross-slip) & 螺位错换一个滑移面——绕过障碍 \\
\hline
\end{longtable}

\subsection{关键概念}

\begin{itemize}
\item \textbf{滑移系}:滑移面 + 滑移方向(FCC 有 12 个,Ch2 讲过)
\item \textbf{临界分切应力(CRSS)}:启动滑移所需的最小分切应力
\item \textbf{Schmid 定律}:$\tau = \sigma\cos\phi\cos\lambda$,分切应力 = 外应力 × Schmid 因子
\item \textbf{Frank-Read 源}:位错的"增殖工厂",一条位错能不断放出新位错环
\end{itemize}

\subsection{塑性变形的宏观表现}

\begin{itemize}
\item \textbf{弹性段}:应力撤去后恢复($\sigma = E\varepsilon$,胡克定律)
\item \textbf{屈服}:位错开始大量运动,产生永久变形
\item \textbf{加工硬化}:塑性变形中强度不断上升
\item \textbf{颈缩与断裂}:变形集中,最终失效(Ch15)
\end{itemize}

\subsection{教科书不讲的事}

\begin{itemize}
\item \textbf{为什么位错让金属"软"了 100 倍}(逐个原子 vs 整层滑移)
\item \textbf{Schmid 因子为什么最大是 0.5}(几何投影的极值)
\item \textbf{加工硬化和 Ch3 的"缺陷越多越强"是同一件事}(位错缠结)
\item \textbf{位错攀移如何把"动"(运动)和"动"(扩散)结合}(高温蠕变)
\end{itemize}

\section{3. 但其实是什么意思}

\subsection{位错让金属"软":地毯褶皱(回顾 Ch3)}

\textbf{Ch3 提过的谜题}:完美晶体让一整层原子同时滑过另一层,需要的应力约是实测的 1000 倍。
\textbf{金属为什么这么"软"}?

\textbf{答案是位错让滑移"逐个原子"进行}。\textbf{移动一大块地毯,你不会整块拖(费力),
而是推一个褶皱过去(省力)}。\textbf{位错就是晶体里的"褶皱"——它一动,
滑移就一个原子一个原子地传过去,所需应力极小}。

\textbf{这就是塑性的本质}:\textbf{宏观的"金属被拉长 1 cm",微观是无数位错滑过晶体、
在表面留下台阶的累积}。

\subsection{Schmid 定律:取向决定难易}

\textbf{位错不是被全部外应力驱动,而是被外应力在滑移面、滑移方向上的"投影"——分切应力驱动}:
$$\tau = \sigma\cos\phi\cos\lambda$$
\textbf{$\phi$ 是滑移面法线与拉伸轴夹角,$\lambda$ 是滑移方向与拉伸轴夹角}。

```{=latex}
\begin{center}
\begin{tikzpicture}[scale=0.85]
  % 拉伸轴
  \draw[->,line width=1.2pt,primarycolor] (0,-1.8) -- (0,1.8) node[above,font=\scriptsize]{拉伸轴 $\sigma$};
  \draw[->,line width=1.2pt,primarycolor] (0,1.8) -- (0,1.8);
  % 滑移面(斜面)
  \draw[staticcolor,thick,fill=staticcolor!12] (-1.5,-0.8) -- (1.5,0.4) -- (1.5,1.0) -- (-1.5,-0.2) -- cycle;
  \node[staticcolor,font=\scriptsize] at (1.9,0.6) {滑移面};
  % 法线
  \draw[->,dynamiccolor,thick] (0,0) -- (-0.7,1.0) node[left,font=\scriptsize]{法线 $\phi$};
  % 滑移方向
  \draw[->,accentcolor,thick] (0,0) -- (1.3,0.5) node[right,font=\scriptsize]{滑移方向 $\lambda$};
  \node[font=\scriptsize] at (0,-2.1) {$\tau = \sigma\cos\phi\cos\lambda$};
\end{tikzpicture}
\end{center}
```

\textbf{Schmid 因子 $m = \cos\phi\cos\lambda$ 最大值是 0.5}(当 $\phi=\lambda=45°$)。\textbf{这意味着}:
\begin{itemize}
\item \textbf{软取向(45°/45°)}:$m=0.5$,分切应力最大,最易变形
\item \textbf{硬取向(轴平行或垂直滑移面)}:$m=0$,分切应力为零,位错根本不动
\end{itemize}

\textbf{这就是为什么单晶有方向性}:\textbf{同一根单晶,沿不同方向拉,屈服强度可以差很多}。

\subsection{加工硬化:越动越硬(连接 Ch3)}

\textbf{位错一动起来,会通过 Frank-Read 源不断增殖}。\textbf{位错越来越多,
它们互相缠结、互相阻挡,后来的位错越来越难动}——\textbf{金属越来越硬}。

\textbf{这正是 Ch3 讲的"缺陷越多越强"——只不过 Ch3 看的是静态的位错密度,
本章看的是位错运动如何制造出这些密度}。\textbf{Taylor 关系 $\Delta\tau = \alpha G b\sqrt{\rho}$
在两章都出现——Ch3 是"结果",Ch10 是"过程"}。

\textbf{铁匠"千锤百炼"的物理}:\textbf{每一锤让位错运动 + 增殖,密度暴涨,金属越来越硬、越来越强}。
\textbf{冷轧、拉拔、喷丸,全是主动用加工硬化来强化}。

\subsection{攀移:当"动"遇上"动"}

\textbf{常温下位错只能滑移(沿滑移面)}。\textbf{但高温下,位错可以"攀移"——
垂直于滑移面运动,越过障碍}。\textbf{攀移需要空位扩散(Ch8)}:位错吸收/发射空位才能上下移动。

\textbf{攀移是高温蠕变的机制}:\textbf{位错运动(本章)+ 空位扩散(Ch8)联手——
两个"动"的过程结合}。\textbf{这就是为什么涡轮叶片在高温长期受力会慢慢变形(蠕变),
而常温不会}。

\section{4. 真正的数学}

\subsection{Schmid 定律}

$$\tau_{\text{RSS}} = \sigma\cos\phi\cos\lambda = \sigma \cdot m$$

\textbf{当分切应力达到临界值 CRSS,滑移启动}:$\sigma_y = \tau_{\text{CRSS}} / m$。
\textbf{$m$ 最大 0.5,所以软取向屈服强度最低}。

\subsection{理论剪切强度}

\textbf{完美晶体整层滑移}:$\tau_{\text{th}} \approx \dfrac{G}{2\pi} \approx \dfrac{G}{10}$。
\textbf{对 $G=45$ GPa,$\tau_{\text{th}}\approx 7$ GPa}。\textbf{但实际退火金属只要 $\sim$50 MPa}——
\textbf{差了百倍,全因位错}。

\subsection{加工硬化(Taylor 关系)}

$$\Delta\tau = \alpha G b\sqrt{\rho}$$

\textbf{位错密度 $\rho$ 随塑性应变增加而增大,$\sqrt{\rho}$ 主导强度上升}。
\textbf{Hollomon 方程描述宏观曲线}:$\sigma = K\varepsilon^n$,$n$ 是加工硬化指数。

\subsection{位错攀移速率}

\textbf{攀移需要空位扩散}:$v_{\text{climb}} \propto D \propto \exp(-Q/RT)$(Arrhenius,同 Ch8)。
\textbf{这是稳态蠕变速率的核心}:$\dot\varepsilon \propto \sigma^n \exp(-Q/RT)$(幂律蠕变)。

\section{5. 一个让人 "Aha" 的例子}

\subsection{核心 Aha:位错让金属"软"了百倍}

运行配套模块 \texttt{dislocation\_motion.py}:

\begin{verbatim}
理论剪切强度(完美晶体整层滑移)≈ G/2π = 7162 MPa
实际屈服强度(退火纯金属)≈ 50 MPa
→ 实际比理论低 143 倍!
\end{verbatim}

\textbf{Aha}:\textbf{如果金属是完美晶体,它应该硬到几乎无法加工(屈服强度 7 GPa)}。
\textbf{但实际退火金属只要 50 MPa 就屈服——低了 143 倍}。\textbf{这个巨大的差距,
全靠位错填平}。\textbf{位错让滑移"逐个原子"进行(地毯褶皱),金属因此"软"到能锻造、
能拉丝、能冲压}。\textbf{没有位错,就没有金属加工业}。

\subsection{Schmid 定律:取向的威力}

\begin{verbatim}
取向                φ    λ    Schmid因子
软取向(45°/45°)     45   45    0.500
中等(30°/60°)      30   60    0.433
硬取向(近90°)       80   10    0.171
轴平行滑移面         90   45    0.000
\end{verbatim}

\textbf{Aha}:\textbf{同一块单晶,沿不同方向拉,屈服强度天差地别}。\textbf{45°/45° 软取向
Schmid 因子 0.5,最易变形;而当拉伸轴平行滑移面时,因子为 0,位错完全不动}。
\textbf{这就是单晶的"各向异性"}——\textbf{涡轮叶片做成单晶且控制取向,
正是利用这一点优化高温性能}。

\subsection{加工硬化:动出来的强}

\begin{verbatim}
变形状态      位错密度(/m²)   应变    强化(MPa)
屈服初期      1e11          0.002    2
中等变形      1e13          0.10    18
重度冷加工    1e15          0.60    178
\end{verbatim}

\textbf{Aha}:\textbf{位错一动就增殖,密度从 $10^{11}$ 暴涨到 $10^{15}$,强度从 2 涨到 178 MPa}。
\textbf{位错运动制造出更多位错,它们互相缠结阻挡,于是金属"越锤越硬"}。\textbf{这和
Ch3 的"缺陷越多越强"是同一件事的两面}:\textbf{Ch3 看静态密度(结果),本章看运动增殖(过程)}。
\textbf{铁匠的"千锤百炼",每一锤都在增加位错密度}。

\subsection{怎么看见它:原位 TEM 与 EBSD}

\begin{bluebox}
\textbf{怎么看见它}。\textbf{Ch3 用 TEM 看位错的"静态几何"(g·b 判据);本章要看位错"运动"——
靠原位 TEM 和 EBSD}。
\end{bluebox}

\textbf{看位错运动的手段}:

\begin{itemize}
\item \textbf{原位 TEM 拉伸}:在电镜里边加载边观察,\textbf{直接"看见"位错滑移、增殖、与障碍交互的动态过程}(实时录像)
\item \textbf{EBSD(电子背散射衍射)}:测晶粒取向 + \textbf{几何必需位错(GND)密度},反映塑性应变分布——\textbf{看"哪里变形了、变形多少"}
\item \textbf{滑移带观察}:位错滑出表面留下台阶,\textbf{表面出现滑移带(肉眼/SEM 可见)}——塑性变形的直接证据
\item \textbf{X 射线/中子衍射峰宽}:位错密度增加导致衍射峰展宽,\textbf{定量测位错密度}(连接 Ch2 的 XRD)
\end{itemize}

\textbf{能测什么}:位错运动速度、增殖机制、滑移系激活、塑性应变分布、位错密度演化。
\textbf{局限}:原位 TEM 样品极薄(表面效应可能不代表块体)、视场小、电子束影响;
\textbf{EBSD 只测表面 + 分辨率有限(几十 nm)};\textbf{滑移带是"事后"证据,看不到过程}。

\textbf{现代视角}:\textbf{原位同步辐射 + 数字图像相关(DIC)能同时获得宏观应变场和微观位错信息;
3D-XRD 能无损追踪体内单个晶粒的取向演化}——\textbf{把"看表面"升级为"看内部"}。

\section{6. 这玩意儿现在在哪}

\subsection{在材料工程中}

\begin{itemize}
\item \textbf{金属成型}:轧制、锻造、拉拔、冲压——全靠位错滑移实现塑性
\item \textbf{强化设计}:加工硬化、固溶强化、析出强化、细晶强化(都是"阻碍位错运动")
\item \textbf{成形性评估}:加工硬化指数 $n$ 决定板材能拉多深(深冲)
\item \textbf{高温部件}:抗蠕变设计(阻碍位错攀移)——涡轮叶片、锅炉管
\end{itemize}

\subsection{在计算材料学中(本书的现代视角)}

\begin{itemize}
\item \textbf{位错动力学(DDD)}:把位错当线缺陷直接模拟运动、增殖、缠结——\textbf{算加工硬化曲线}
\item \textbf{分子动力学(MD,Ch14)}:原子尺度模拟位错形核、运动、与障碍交互
\item \textbf{晶体塑性有限元(CPFEM)}:把 Schmid 定律嵌入有限元(Ch13),算多晶变形
\item \textbf{DFT 算层错能}:决定位错如何分解、交滑移难易
\end{itemize}

\begin{bluebox}
\textbf{计算材料学怎么看位错运动}:本章的 Schmid 定律,\textbf{是晶体塑性有限元(CPFEM,接 Ch13 的 FEM)
的核心本构};\textbf{位错动力学(DDD)直接模拟本章描述的滑移与增殖}。\textbf{多尺度暗线在此体现}:
\textbf{原子(MD 看单个位错)→ 介观(DDD 看位错集体)→ 宏观(CPFEM 看构件变形)}——
\textbf{位错运动贯穿了全书的多尺度计算主线}。
\end{bluebox}

\subsection{在日常材料中}

\begin{itemize}
\item \textbf{为什么回形针反复弯会越来越硬最后断}:加工硬化 + 位错塞积(Ch3)→ 断裂
\item \textbf{为什么金属勺子能掰弯不回弹}:超过屈服,位错滑移产生永久塑性
\item \textbf{为什么易拉罐能冲压成型}:铝的 FCC 结构 12 个滑移系,塑性好
\item \textbf{为什么高温下金属会"软"和"蠕变"}:位错攀移 + 扩散激活
\end{itemize}
