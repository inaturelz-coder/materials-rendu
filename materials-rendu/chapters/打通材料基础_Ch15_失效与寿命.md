\section{1. 一句话本质}

\begin{bluebox}
\textbf{材料失效有四种主要模式,每一种都有可量化的机理和寿命预测方法}:

\textbf{断裂}(裂纹失稳扩展)、\textbf{疲劳}(循环载荷)、\textbf{蠕变}(高温长期)、\textbf{腐蚀}(电化学)。

\vspace{0.3em}

\textbf{三句话记住这一章}:

\textbf{1. 断裂看 $K_{IC}$}:应力强度因子 $K=Y\sigma\sqrt{\pi a}$ 达到断裂韧性 $K_{IC}$ 就断——临界裂纹尺寸是关键。

\textbf{2. 疲劳是头号杀手}:80\% 机械失效是疲劳,应力远低于强度也会断(循环累积)。

\textbf{3. 失效是全书的总审判}:断裂(Ch13)、疲劳(Ch10)、蠕变(Ch8+10)、腐蚀(Ch1+5)。

\vspace{0.3em}

\textbf{实测核心 Aha}:\textbf{陶瓷的临界裂纹只有 0.1 mm(肉眼难见就崩),韧性钢能容忍 16 mm};
\textbf{疲劳:应力幅降一点,寿命涨几个数量级};\textbf{蠕变:500→800°C 速率涨 46 万倍(攀移靠扩散)};
\textbf{腐蚀:用更活泼的锌保护铁(牺牲阳极)——电化学序的应用}。
\end{bluebox}

\begin{itemize}
\item \textbf{Griffith 判据}:裂纹扩展释放的弹性能 $\geq$ 新表面能
\item \textbf{应力强度因子}:$K = Y\sigma\sqrt{\pi a}$
\item \textbf{断裂韧性 $K_{IC}$}:材料抵抗裂纹扩展的能力
\item \textbf{临界裂纹尺寸}:$K = K_{IC}$ 时的裂纹长度
\end{itemize}

\item \textbf{疲劳极限}:钢有(应力低于此无限寿命),铝没有
\item \textbf{三阶段}:裂纹萌生(表面)→ 稳定扩展 → 失稳断裂
\end{itemize}

\section{3. 但其实是什么意思}

\subsection{断裂:裂纹是放大器(接 Ch13)}

\textbf{Ch13 讲了应力集中:孔、缺口、裂纹处应力放大}。\textbf{裂纹尖端理论上应力趋于无穷}。
\textbf{断裂力学用"应力强度因子" $K$ 来定量描述裂纹尖端的应力强度}:
$$K = Y\sigma\sqrt{\pi a}$$

\textbf{当 $K$ 达到材料的"断裂韧性" $K_{IC}$,裂纹失稳扩展——瞬间断裂}。\textbf{关键洞察}:
\textbf{存在一个"临界裂纹尺寸" $a_c$——小于它的裂纹安全,大于它灾难}。

\textbf{这解释了脆性与韧性的本质区别}:\textbf{陶瓷 $K_{IC}$ 极低,临界裂纹只有几十微米
(肉眼看不见的划痕就能让它崩);韧性金属 $K_{IC}$ 高,能容忍毫米级裂纹}。
\textbf{所以陶瓷怕磕碰,金属能"带伤工作"}。

\subsection{疲劳:沉默的头号杀手(接 Ch10)}

\textbf{80\% 的机械失效是疲劳}。\textbf{可怕之处}:\textbf{应力远低于屈服强度,
只要反复加载足够多次,也会突然断裂}——\textbf{没有预兆}。

\textbf{机理连着 Ch10 的位错}:\textbf{循环载荷下,位错往复运动,在表面挤出/挤入台阶,
萌生微裂纹}。\textbf{裂纹每个循环扩展一点(留下"疲劳辉纹"),最终失稳断裂}。

\textbf{S-N 曲线}描述应力幅与寿命的关系:\textbf{应力越高寿命越短}。\textbf{钢有"疲劳极限"——
应力低于某值可无限循环;铝合金没有——总会失效}。\textbf{这就是飞机有"疲劳寿命"、
要定期检修的原因(彗星号空难就是疲劳 + 应力集中)}。

\subsection{蠕变:高温的双动(接 Ch8 + Ch10)}

\textbf{蠕变 = 高温下长期受力的缓慢变形}。\textbf{常温不会,但高温下,即使应力低于屈服,
材料也会慢慢"流动"}。

\textbf{机理是 Ch8 和 Ch10 的结合}:\textbf{位错攀移(Ch10)越过障碍,需要空位扩散(Ch8)}。
\textbf{所以蠕变速率同时依赖应力(幂律 $\sigma^n$)和温度(Arrhenius $e^{-Q/RT}$)}:
$$\dot\varepsilon = A\sigma^n \exp\left(-\frac{Q}{RT}\right)$$

\textbf{这是涡轮叶片、锅炉管、核电部件的寿命杀手}——\textbf{它们在高温高应力下长期服役,
蠕变决定了它们能用多久}。\textbf{抗蠕变设计 = 阻碍位错攀移 + 提高熔点(降低扩散)}。

\subsection{腐蚀:电化学的代价(接 Ch1 + Ch5)}

\textbf{腐蚀连着全书的开头}:\textbf{Ch1 的电子转移倾向(电负性)、Ch5 的氧化自由能($\Delta G < 0$)}。
\textbf{金属氧化(生锈)是自发的——因为氧化物自由能更低}。

\textbf{电化学序}按电极电位排列金属:\textbf{电位越负越活泼(易腐蚀),越正越惰性(耐蚀)}。
\textbf{两种金属接触会发生"电偶腐蚀"——活泼的被腐蚀,惰性的被保护}。

\textbf{防护的智慧——逆用电化学序}:\textbf{镀锌(锌比铁活泼,优先腐蚀保护铁)、
牺牲阳极(船体挂锌块)、阴极保护}。\textbf{铝看似活泼,却耐蚀——因为表面快速形成
致密 Al$_2$O$_3$ 钝化膜(动力学保护,呼应 Ch5)}。

\section{4. 真正的数学}

\subsection{应力强度因子与临界裂纹}

$$K = Y\sigma\sqrt{\pi a}, \qquad a_c = \frac{1}{\pi}\left(\frac{K_{IC}}{Y\sigma}\right)^2$$

\textbf{$a_c$ 是临界裂纹尺寸}。\textbf{$K_{IC}$ 越大(越韧)、应力越低,能容忍的裂纹越大}。

\subsection{Paris 定律(疲劳裂纹扩展)}

$$\frac{\mathrm{d}a}{\mathrm{d}N} = C(\Delta K)^m$$

\textbf{裂纹每循环扩展量正比于应力强度因子幅度的 $m$ 次方}。\textbf{积分给出剩余寿命}。

\subsection{Basquin 定律(S-N)}

$$\sigma_a = \sigma_f'(2N)^b$$

\textbf{应力幅与寿命的幂律关系}。\textbf{$b$ 是疲劳强度指数(负值)}。

\subsection{稳态蠕变(接 Ch10 攀移)}

$$\dot\varepsilon = A\sigma^n\exp\left(-\frac{Q}{RT}\right)$$

\textbf{应力幂律($n\sim 3$-$8$,位错蠕变)+ 温度 Arrhenius($Q$ = 扩散激活能,Ch8)}。
\textbf{这把 Ch8(扩散)、Ch10(位错)在"蠕变"里合成了一个公式}。

\section{5. 一个让人 "Aha" 的例子}

\subsection{核心 Aha:陶瓷的"小裂纹大灾难"}

运行配套模块 \texttt{failure\_life.py}:

\begin{verbatim}
材料         K_IC   应力MPa   临界裂纹(mm)
高强钢       50     1000      0.63
铝合金       30     300       2.54
陶瓷Al2O3    4      200       0.10
韧性钢       100    400       15.86
\end{verbatim}

\textbf{Aha}:\textbf{陶瓷的临界裂纹只有 0.1 mm——一道肉眼几乎看不见的划痕,
就足以让它灾难性崩裂}。\textbf{而韧性钢能容忍 16 mm 的裂纹还不断}。\textbf{这就是
"脆 vs 韧"的定量本质}:\textbf{不是陶瓷"强度低"(它抗压很强),而是它的断裂韧性 $K_{IC}$ 极低,
对裂纹极其敏感}。\textbf{所以陶瓷刀锋利但怕磕,金属钝些但能带伤工作}。

\subsection{Aha:疲劳——应力降一点,寿命涨百倍}

\begin{verbatim}
应力幅(MPa)   循环寿命(次)
600           2.88e+01    ← 28次就断
450           5.12e+02
350           6.32e+03
280           5.89e+04
250           1.83e+05    ← 18万次
\end{verbatim}

\textbf{Aha}:\textbf{应力幅从 600 降到 250 MPa(降一半多),寿命从 28 次涨到 18 万次(涨几千倍)}。
\textbf{疲劳寿命对应力极其敏感}。\textbf{而且钢有"疲劳极限"——应力低于 $\sim$250 MPa 可无限循环;
铝合金没有,总会失效}。\textbf{这就是为什么飞机(铝合金)必须定期检修、有"疲劳寿命",
而桥梁(钢)设计在疲劳极限以下可"永久"使用}。

\subsection{Aha:蠕变——温度的指数威力}

\begin{verbatim}
温度°C   蠕变速率(相对)
500      5.4e-16
600      1.1e-13
700      7.9e-12
800      2.5e-10
→ 500→800°C,速率增大 46万倍
\end{verbatim}

\textbf{Aha}:\textbf{温度从 500 升到 800°C,蠕变速率暴增 46 万倍}。\textbf{因为蠕变靠位错攀移,
攀移靠空位扩散(Ch8),而扩散是 Arrhenius 指数依赖温度}。\textbf{这就是为什么航空发动机
追求"耐更高温度"——每提高几十度,要么寿命大增,要么效率大增}。\textbf{单晶叶片、
定向凝固、热障涂层,全是为了抗蠕变}。

\subsection{怎么看见它:断口分析与无损检测}

\begin{bluebox}
\textbf{怎么看见它}。\textbf{失效分析靠"断口分析"(看断了之后的样子)+ 无损检测(在失效前发现裂纹)}。
\end{bluebox}

\textbf{失效分析与寿命管理的手段}:
\begin{itemize}
\item \textbf{断口分析(fractography,SEM)}:看断口形貌——\textbf{韧窝(韧性)、解理面(脆性)、
疲劳辉纹(疲劳)、沿晶断裂(蠕变/腐蚀)}——\textbf{断口"写"着失效的全部故事}
\item \textbf{无损检测(NDT)}:超声、X 射线、涡流、渗透——\textbf{在零件失效前发现内部裂纹}
\item \textbf{金相(Ch4)}:看组织退化、裂纹路径(沿晶/穿晶)
\item \textbf{应变监测}:应变片、DIC(Ch13)实时监测关键部件
\end{itemize}

\textbf{失效分析的逻辑}:\textbf{断口形貌反推失效模式}——\textbf{疲劳辉纹说明是疲劳;
解理面说明脆断;韧窝说明韧性过载;沿晶 + 蠕变孔洞说明蠕变}。\textbf{能做什么}:
确定失效模式、起裂位置、裂纹扩展历史、根本原因。\textbf{局限}:断口可能被二次损伤污染;
需要经验判读;\textbf{失效分析是"事后",寿命预测才是"事前"}。

\textbf{现代视角}:\textbf{结构健康监测(SHM)+ 数字孪生——传感器实时数据 + 计算模型,
预测剩余寿命;机器学习从历史失效数据预测};\textbf{断裂力学 + FEM(Ch13)算裂纹扩展寿命}。
