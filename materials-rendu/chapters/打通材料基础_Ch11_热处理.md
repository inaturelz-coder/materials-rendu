\section{1. 一句话本质}

\begin{bluebox}
\textbf{热处理 = 用"温度 + 时间"控制组织,从而控制性能}。\textbf{核心是控制冷速:
慢冷让原子充分扩散(走向平衡相),快冷冻住扩散(逼出非平衡相)}。

\vspace{0.3em}

\textbf{马氏体之谜的解答}:\textbf{奥氏体(FCC,溶碳多)快冷时,碳来不及扩散出去,
晶格被迫无扩散地切变成 BCT(体心四方),碳被困在里面过饱和}——\textbf{这就是马氏体,
超硬但脆}。

\vspace{0.3em}

\textbf{三句话记住这一章}:

\textbf{1. 同一块钢,冷速决定组织}:慢冷→珠光体(软),快冷→马氏体(硬),硬度可差 4 倍。

\textbf{2. 马氏体转变无扩散}:只看"冷到多少温度",与时间无关(Koistinen-Marburger)。

\textbf{3. 动力学战胜热力学}:相图说该得珠光体(静),淬火躲过鼻尖逼出马氏体(动)。

\vspace{0.3em}

\textbf{实测核心 Aha}:\textbf{同成分钢,冷速从 0.01 到 1000°C/s,硬度从 15 飙到 65 HRC};
\textbf{马氏体转变量只取决于温度($M_s=218°C$),降温就转,不降温不转,与时间无关};
\textbf{回火是硬度与韧性的权衡(刀刃低温回火保硬,弹簧高温回火求韧)}。
\end{bluebox}

\section{2. 教科书里你看到的}

\subsection{Fe-C 相图(钢的圣经)}

\begin{itemize}
\item \textbf{共析点}:0.76\% C,727°C
\item \textbf{共析反应}:$\gamma(0.76\%\text{C}) \to \alpha(0.022\%\text{C}) + \text{Fe}_3\text{C}$
\item \textbf{珠光体}:共析反应的产物,铁素体 + 渗碳体的层片状组织
\item \textbf{奥氏体($\gamma$,FCC)溶碳多(最高 2.14\%),铁素体($\alpha$,BCC)几乎不溶碳}
\end{itemize}

\subsection{常见热处理工艺}

\begin{longtable}{|l|p{0.6\textwidth}|}
\hline
\rowcolor{primarycolor!10}
\textbf{工艺} & \textbf{做法与目的} \\
\hline
退火 & 缓冷,得平衡组织——软化、消除应力、改善加工性 \\
正火 & 空冷,稍快——细化晶粒、提高强度 \\
淬火 & 急冷(水/油)——得马氏体,硬化 \\

\hline

\subsection{淬火得到的组织(随冷速)}

\begin{itemize}
\item \textbf{珠光体}:慢冷,扩散充分(粗/细)
\item \textbf{贝氏体}:中速冷,半扩散
\item \textbf{马氏体}:快冷(超过临界速率),无扩散切变
\end{itemize}

\subsection{教科书不讲的事}

\begin{itemize}
\item \textbf{马氏体为什么是 BCT 而非 BCC}(碳被困住撑变了晶格)
\item \textbf{为什么马氏体转变与时间无关}(无扩散的本质)
\item \textbf{为什么淬火得马氏体是"动力学战胜热力学"}(全书主轴的顶点)
\item \textbf{淬透性为什么靠合金元素}(让 TTT 鼻尖右移)
\end{itemize}

\section{3. 但其实是什么意思}

\subsection{马氏体之谜:一步步解开}

\textbf{让我们跟着一块共析钢(0.76\% C)走一遍}:

\textbf{第一步——加热到奥氏体}:\textbf{加热到 727°C 以上,钢变成奥氏体($\gamma$,FCC)}。
\textbf{FCC 能溶解大量碳(Ch2 的同素异构 + 间隙固溶)}。\textbf{此时碳均匀溶在 FCC 里}。

\textbf{第二步——慢冷(走平衡)}:\textbf{如果慢冷,碳有时间扩散,奥氏体分解成珠光体
(铁素体 + 渗碳体层片)}——\textbf{这就是相图(Ch6)预言的平衡组织}。\textbf{软,$\sim$15 HRC}。

\textbf{第三步——快冷(躲鼻尖)}:\textbf{如果急冷,在 TTT 鼻尖(Ch9)那个"转变最快的温度"
快速掠过——扩散来不及发生}。\textbf{碳被困在 FCC 晶格里出不来}。

\textbf{第四步——无扩散切变}:\textbf{温度继续降到 $M_s$,FCC 再也撑不住,
瞬间无扩散地切变成 BCT(体心四方)}。\textbf{碳没跑掉,被困在 BCT 里——过饱和}。
\textbf{过饱和的碳把立方撑成了四方(c/a > 1),加上切变畸变,产生巨大内应力}——
\textbf{这就是马氏体,超硬($\sim$65 HRC)但脆}。

\begin{bluebox}
\textbf{谜底}:\textbf{相图(静)说该得珠光体,但那需要"时间"让碳扩散}。
\textbf{淬火(动)不给时间——躲过 TTT 鼻尖,冻住扩散,逼出无扩散切变的马氏体}。
\textbf{动力学(冷速)战胜了热力学(相图)}。\textbf{这是全书"一静一动"的终极对决}。
\end{bluebox}

\subsection{为什么马氏体转变与时间无关}

\textbf{珠光体转变需要扩散,所以需要"时间"(TTT 曲线是时间-温度图)}。\textbf{但马氏体转变是
无扩散切变——原子集体移动小于一个原子间距,瞬间完成(声速量级)}。

\textbf{所以马氏体转变量只取决于"冷到多少温度",与停留时间无关}:
\textbf{Koistinen-Marburger 方程 $f = 1 - e^{-\alpha(M_s - T)}$}。\textbf{降温就转,
停在某温度不再转,继续降温才继续转}。\textbf{这是马氏体最反直觉、也最深刻的特征}。

\subsection{回火:给马氏体"松绑"}

\textbf{刚淬火的马氏体太脆,几乎不能用}(内应力大、碳过饱和)。\textbf{回火——
重新加热到中低温——让部分碳析出成细小碳化物,释放内应力}。

\textbf{回火是硬度与韧性的权衡}:
\begin{itemize}
\item \textbf{低温回火(150-250°C)}:保留高硬度,略增韧——\textbf{刀刃、轴承}
\item \textbf{中温回火(350-450°C)}:平衡硬韧——\textbf{弹簧}
\item \textbf{高温回火(500-650°C)}:大幅增韧,降硬——\textbf{齿轮、轴(调质)}
\end{itemize}

\subsection{淬透性:为什么大零件要合金钢}

\textbf{淬火时,表面冷得快(得马氏体),芯部冷得慢(可能得珠光体)}。\textbf{淬透性 = 钢"淬硬到多深"的能力}。

\textbf{合金元素(Cr、Ni、Mo)的作用}:\textbf{让 TTT 鼻尖"右移"(转变更慢)}——
\textbf{这样即使芯部冷得慢,也能躲过鼻尖、得到马氏体}。\textbf{所以大截面零件必须用合金钢}。

\section{4. 真正的数学}

\subsection{马氏体开始温度}

$$M_s(°C) = 539 - 423\,(\%\text{C}) - 30.4\,(\%\text{Mn}) - \ldots$$

\textbf{碳含量越高,$M_s$ 越低}(碳稳定奥氏体)。\textbf{高碳钢可能 $M_f$ 低于室温,
留有残余奥氏体}。

\subsection{Koistinen-Marburger 方程}

$$f_{\text{martensite}} = 1 - \exp[-\alpha(M_s - T)], \quad T < M_s$$

\textbf{注意:右边只有温度 $T$,没有时间 $t$}——\textbf{这数学地表达了"马氏体转变无扩散、与时间无关"}。

\subsection{亚共析钢的组织(杠杆定律)}

\textbf{0.4\% C 钢慢冷,727°C 刚上方,先共析铁素体 + 剩余奥氏体(将变珠光体)}:
$$f_{\alpha} = \frac{0.76 - 0.40}{0.76 - 0.022} = 0.49, \quad f_{\text{pearlite}} = 0.51$$
(复用 Ch4/Ch6 的杠杆定律)。

\subsection{临界冷却速率}

\textbf{要得到全马氏体,冷速必须超过"临界冷却速率"——快到躲过 TTT 鼻尖}。
\textbf{鼻尖越靠左(转变越快),需要的冷速越高}。\textbf{合金化让鼻尖右移,降低临界冷速}。

\section{5. 一个让人 "Aha" 的例子}

\subsection{核心 Aha:同成分钢,冷速决定一切}

运行配套模块 \texttt{heat\_treatment.py}:

\begin{verbatim}
冷速(°C/s)   组织      硬度HRC   机制
0.01        粗珠光体    15      完全扩散(平衡)
1           细珠光体    25      扩散(接近平衡)
50          贝氏体      45      半扩散
200         马氏体      65      无扩散切变(躲过鼻尖!)
1000        马氏体      65      无扩散切变(躲过鼻尖!)
\end{verbatim}

\textbf{Aha}:\textbf{成分一模一样的钢,只改变冷速,硬度从 15 飙到 65 HRC(差 4 倍多)}。
\textbf{慢冷给扩散时间→走向平衡的珠光体(软);快冷躲过鼻尖→逼出马氏体(硬)}。
\textbf{这就是"组织决定性能"(全书主旋律)+ "动力学战胜热力学"(全书主轴)的完美合体}。
\textbf{铁匠淬刀、热处理车间淬齿轮,全靠这一条}。

\subsection{马氏体转变:只看温度,不看时间}

\begin{verbatim}
共析钢(0.76%C): Ms=218°C, Mf=3°C
温度°C    马氏体分数
218       0.000   ← 刚到 Ms,开始转变
168       0.423
118       0.667
68        0.808
3         0.906   ← Mf 附近,基本转完
\end{verbatim}

\textbf{Aha}:\textbf{马氏体转变量只取决于"冷到多少温度"——降温就转,停住就不转,与时间完全无关}。
\textbf{这彻底不同于珠光体(需要时间扩散)}。\textbf{原因:马氏体是无扩散切变,
原子集体移动不到一个原子间距,以声速瞬间完成}。\textbf{这是"动"的极致——
快到扩散完全跟不上}。

\subsection{回火:鱼和熊掌}

\begin{verbatim}
回火温度°C   硬度HRC   韧性(相对)
150         56        32   ← 刀刃(保硬)
300         47        55
450         38        78
600         29        100  ← 弹簧/轴(求韧)
\end{verbatim}

\textbf{Aha}:\textbf{回火温度越高,越软越韧——硬度和韧性是一对矛盾}。\textbf{刀刃要硬(低温回火),
弹簧要韧(高温回火)}。\textbf{一把好刀:刀刃淬硬 + 低温回火(锋利耐磨),刀背保持韧性(不崩)}——
\textbf{这就是"局部热处理"的智慧,中国古代的"夹钢""嵌钢"工艺早就在用}。

\subsection{怎么看见它:金相 + 硬度 + 膨胀法}

\begin{bluebox}
\textbf{怎么看见它}。\textbf{热处理的组织和相变,靠金相(看组织)+ 硬度计(测性能)
+ 膨胀法(测相变,接 Ch9)综合判断}。
\end{bluebox}

\textbf{热处理评价的标准手段}:
\begin{itemize}
\item \textbf{金相显微镜(Ch4)}:腐蚀后看组织——\textbf{珠光体(层片状)、贝氏体(羽毛/针状)、
马氏体(针状/板条),形貌截然不同}
\item \textbf{硬度计}:洛氏硬度(HRC)、维氏硬度——\textbf{快速判断淬火效果}(马氏体硬、珠光体软)
\item \textbf{膨胀法(Ch9)}:相变伴随体积变化,\textbf{测淬火时 $M_s$、$M_f$ 温度,构建 CCT 曲线}
\item \textbf{XRD(Ch2)}:测残余奥氏体量、马氏体的 BCT 四方度(c/a)
\item \textbf{Jominy 端淬试验}:一端淬火,沿长度测硬度——\textbf{标准化评价淬透性}
\end{itemize}

\textbf{能测什么}:组织类型、各相比例、硬度分布、相变温度、淬透性、残余奥氏体。
\textbf{局限}:金相是"事后"组织(看不到相变过程);硬度是宏观平均;\textbf{马氏体针太细时
光学金相分辨不清,需 SEM/TEM}。

\textbf{现代视角}:\textbf{原位高温 XRD / 膨胀法实时追踪相变;EBSD 分辨马氏体的板条/取向;
CALPHAD + 动力学软件(如 JMatPro)直接计算 TTT/CCT 曲线和组织——把"试错"变成"预测"}。

\subsection{思考题}

\begin{enumerate}
\item \textbf{(马氏体)} 用 \texttt{martensite\_start} 算 0.2\%C 和 1.0\%C 钢的 $M_s$。
为什么高碳钢淬火后常有残余奥氏体?(提示:$M_f$ 可能低于室温)

\item \textbf{(无扩散)} 为什么马氏体转变与时间无关,而珠光体转变需要时间?
